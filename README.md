 Sunita E-Commerce Sales Dashboard (Power BI)

📌 Project Overview

This project presents an interactive E-commerce Sales Dashboard built using Power BI. It helps analyze sales, profit, quantity, and customer trends across different states, categories, and payment modes.

---

🎯 Objective

- Analyze overall sales performance
- Track profit trends over months
- Identify top-performing categories and sub-categories
- Understand customer and payment behavior

---

📊 Dashboard Highlights

🔢 Key Metrics (KPIs)

- Total Sales Amount: 438K
- Total Profit: 37K
- Total Quantity Sold: 5615
- Average Order Value (AOV): 121

---

📈 Visual Insights

📍 Sales by State

- Maharashtra contributes highest sales
- Followed by Madhya Pradesh and Uttar Pradesh

🛍 Category-wise Quantity

- Clothing: 63% (highest)
- Electronics: 21%
- Furniture: 17%

💳 Payment Mode Analysis

- COD: 43.74% (most used)
- UPI: 20.61%
- Debit Card & Credit Card contribute moderate share

📅 Profit by Month

- Strong profits in January, February, December
- Loss observed in some mid-year months

👥 Top Customers

- Harivansh, Madhav, Madan Mohan, Shiva contribute major sales

📦 Profit by Sub-Category

- Printers generate highest profit
- Followed by Bookcases and Sarees
